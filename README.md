## 게임 설정 방법
- Releases 탭에서 플러그인을 다운로드 할 수 있습니다.
- 서버 실행 방법을 모르는 경우 아래 방법을 따라 서버를 제작할 수 있습니다.
- 폴더를 하나 생성하고 각 OS에 맞게 터미널에서 아래 명령어를 실행합니다.
  - Windows: `irm https://raw.githubusercontent.com/ | iex`
  - MacOS / Linux: `curl -s https://raw.githubusercontent.com/ | bash`
- 명령어 실행시 자동으로 서버가 세팅되며, Windows의 경우 `start.bat`, MacOS / Linux의 경우 `start.sh`를 실행하면 서버가 시작됩니다.

## 게임 플레이 방법
- 게임 규칙은 [드래곤 알 서바이벌 나무위키](https://namu.wiki/w/%EB%93%9C%EB%9E%98%EA%B3%A4%20%EC%95%8C%20%EC%84%9C%EB%B0%94%EC%9D%B4%EB%B2%8C#s-3)를 참고해주세요.
- 플러그인을 적용하고 서버를 실행하면 자동으로 게임이 시작됩니다.
- 마인크래프트 월드의 날짜 시스템은 기본적으로 Day 0부터 시작하지만, 편의를 위해 Day 1부터 시작하도록 설정되어 있습니다.
